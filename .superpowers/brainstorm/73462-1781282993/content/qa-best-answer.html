Who can mark a Best Answer?

When a Q&A thread gets a reply that fully answers the question, who gets to mark it as resolved?

A

Original poster only

Only the person who asked the question can mark the best answer. Their thread, their call.

Pros

  • Simple, no disputes
  • Answerer earns rep only when asker agrees

Cons

  • Thread stays unresolved if OP goes inactive
B

OP + moderators (Recommended)

The asker marks their own answer. If they're inactive, a mod can step in and mark it resolved to keep the thread useful.

Pros

  • Threads don't go stale
  • Mods can curate quality answers

Cons

  • Mods must occasionally review threads
C

Anyone (community-voted)

Like Stack Overflow — the highest-upvoted answer automatically gets the "accepted" highlight, no manual marking needed.

Pros

  • Fully automated, scales well
  • No inactive-OP problem

Cons

  • Popular ≠ correct; first good answer may not win
