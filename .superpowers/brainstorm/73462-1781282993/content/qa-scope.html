Q&A Format — which threads can be Q&A?

The Q&A format adds a "mark best answer" button and sorts by votes. Where should it apply?

A

Category-level — specific categories are Q&A only

Admins mark certain forum categories as "Q&A" type. All threads in that category automatically get the Q&A format. Clean, predictable — a "Help & Questions" category is always Q&A.

Pros

  • No per-thread decision needed
  • Users know what to expect per category

Cons

  • Can't have a Q&A thread in a Discussion category
B

Thread-level — author chooses when creating

A toggle when composing a new thread: "This is a question — mark best answer when resolved." Works in any category.

Pros

  • Flexible — questions can appear anywhere
  • Author intent is explicit

Cons

  • Relies on users remembering to toggle it
C

Both — category default + per-thread override (Recommended)

Categories can be set to Q&A mode (all threads default to Q&A), but any thread can override it either way. Most flexible.

Pros

  • Best of both worlds
  • Help category auto-enables Q&A; edge cases still work

Cons

  • Slightly more schema work
