New components summary

Forum.js
Router — renders category list, thread list, or thread view based on URL
ForumCategoryList.js
2×2 grid of category cards with thread counts
ForumCategoryView.js
Paginated thread list with sort, pinned + locked badges
ForumThreadView.js
Thread + nested posts + reply composer + upvotes
ForumPostComposer.js
Shared composer for threads and replies — [[Card]] syntax, deck attach button
Admin: ForumModerationTab.js
Mute/unmute users, view mute history — lives in Admin → Community
