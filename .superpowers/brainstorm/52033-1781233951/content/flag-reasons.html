Should users pick a reason when flagging?

Helps mods triage faster — but adds friction to the reporting flow.

A

One-tap flag — no reason

Tap the flag icon, done. The post goes into the mod queue as-is. Low friction, fastest path.

B

Required category

User must pick one before submitting:

  • 🚫 Spam or self-promotion
  • ⚠️ Harassment or abuse
  • 🔞 Inappropriate content
  • 💬 Off-topic
C

Optional note

Flag submits immediately, but a small textarea lets the user add context if they want. Not required.
