How is a shadow ban applied?

Shadow-banned users see their own posts normally — no one else does. It isolates them without alerting them.

A

Manual only — admin applies it

Only an admin can shadow ban a user from the admin panel. It's a deliberate moderation decision, never automatic.

Pros

  • No accidental shadow bans
  • Simple — one input, one action

Cons

  • Requires admin to manually review and act
B

Auto-trigger after repeated flags

If a user has 3+ pieces of content flagged and confirmed bad by a mod, they're automatically shadow banned.

Pros

  • Scales without constant admin action
  • Repeat offenders caught automatically

Cons

  • Risk of false positives from brigading
  • More complex logic
C

Manual, but system suggests it

Admin applies it manually, but the flag queue highlights users with multiple confirmed violations and suggests shadow banning them.

Pros

  • Admin stays in control
  • Pattern-based nudge speeds up decisions

Cons

  • Slightly more UI work
