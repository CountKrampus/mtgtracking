What should users be able to flag?

Flagging lets users report bad content for moderator review. Where should it apply?

A

Forum only

Threads and replies in the forum. Chat messages and card comments are already handled by the existing Content Moderation admin tab.

Pros

  • Focused scope, less complexity
  • Forum is the main public space
  • Faster to build

Cons

  • Chat / comments have no user-driven reporting
B

All user content

Forum threads, forum replies, chat messages, and card discussion comments — one unified flag queue in the admin panel.

Pros

  • Complete coverage
  • Single review workflow for mods

Cons

  • More complex — chat messages are ephemeral
  • Larger build
C

Forum + Chat

Forum threads/replies and chat messages. Card comments are lower-volume and already moderated by admins directly.

Pros

  • Covers the two highest-traffic areas
  • Balanced scope

Cons

  • Slightly more work than forum-only
