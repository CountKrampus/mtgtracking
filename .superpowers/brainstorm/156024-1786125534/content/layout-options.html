Which layout works best for comparing two decks?

Each deck's commander shown separately up top. Below it: shared cards, and each deck's unique cards. Think about how this holds up on a phone-width screen too, since this app leans mobile-heavy.

A  Two Columns + Shared Bar

Mirrors the existing Collection Comparison: a "shared cards" strip across the top, then two side-by-side columns for each deck's unique cards. On mobile the two columns stack vertically.

B  Three Columns Side-by-Side

A literal Venn diagram in table form: Only-A | Shared | Only-B all visible at once on desktop. On mobile this becomes a horizontally swipeable 3-panel strip since 3 columns can't fit a phone width.

C  Stats First, Filterable Card List Below

Top: mana curve + color pip comparison as overlaid bar charts (the "at a glance" view). Below: a single card list with a filter toggle (All / Shared / Only A / Only B) instead of fixed columns — naturally mobile-friendly since it's just one column that never needs to split.
