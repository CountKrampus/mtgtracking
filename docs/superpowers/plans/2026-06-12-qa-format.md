# Q&A Format — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow forum categories and threads to be marked as Q&A-type. In Q&A threads, the highest-upvoted reply (≥3 upvotes) is automatically highlighted as the "Best Answer". Thread lists show ✅ Answered / ❓ Unanswered status badges. The best-answer author earns a +15 rep bonus (one-time).

**Architecture:** `isQA` is added to `ForumCategory` and `ForumThread` schemas. `bestAnswerPostId` is stored on `ForumThread` and updated in the post upvote handler. Best-answer detection runs synchronously in the upvote route because it changes the thread document. The Q&A toggle is sent in the POST /threads request body; thread creation inherits `isQA` from its category. The frontend pins the best-answer post at the top of the reply list in `ForumThreadView` and shows status badges in `ForumCategoryView`.

**Dependency:** Requires the `reputation` integer field from the Gamification plan (Task 1 of `2026-06-12-gamification.md`). Implement that plan's Task 1 first if it has not been done.

**Tech Stack:** Node.js + Express + Mongoose, React + Tailwind CSS

In `backend/routes/forum.js`, replace the full `POST /api/forum/posts/:id/upvote` handler with:

```javascript
// POST /api/forum/posts/:id/upvote — toggle; runs best-answer detection for QA threads
router.post('/posts/:id/upvote', verifyToken, requireAuth, async (req, res) => {
  try {
    const post = await ForumPost.findById(req.params.id);
    if (!post) return res.status(404).json({ message: 'Post not found' });

    const uid = req.user._id;
    const idx = post.upvotes.findIndex(id => id.toString() === uid.toString());
    const isAdding = idx === -1;

    if (isAdding) {
      post.upvotes.push(uid);
      // +5 rep to post author (fire-and-forget, not self-upvote)
      if (post.authorId.toString() !== uid.toString()) {
        User.findByIdAndUpdate(post.authorId, { $inc: { reputation: 5 } }).catch(() => {});
      }
    } else {
      post.upvotes.splice(idx, 1);
    }
    await post.save();

    // Best-answer detection for Q&A threads
    const thread = await ForumThread.findById(post.threadId);
    if (thread?.isQA) {
      const allPosts = await ForumPost.find({ threadId: thread._id })
        .select('_id authorId upvotes').lean();
      const topPost = allPosts.reduce((best, p) =>
        p.upvotes.length > (best?.upvotes.length || 0) ? p : best, null);

      const prevBestId = thread.bestAnswerPostId?.toString();
      const newBestId = topPost && topPost.upvotes.length >= 3 ? topPost._id.toString() : null;

      thread.bestAnswerPostId = newBestId ? topPost._id : null;
      await thread.save();

      // Award +15 rep to new best-answer author (one-time: only when bestAnswerPostId changes to this post)
      if (newBestId && newBestId !== prevBestId && topPost.authorId.toString() !== uid.toString()) {
        User.findByIdAndUpdate(topPost.authorId, { $inc: { reputation: 15 } }).catch(() => {});
      }
    }

    res.json({ upvoteCount: post.upvotes.length, hasUpvoted: isAdding });
  } catch (e) { res.status(500).json({ message: e.message }); }
});
```
